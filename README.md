# Roman Perk's portfolio

Personal site of Roman Perk, a software engineer at 2N. One page with experience, projects and contact details.

Built with React, TypeScript, Vite and Tailwind CSS, and deployed on Vercel.

## Run it

```sh
npm install
npm run dev
```

Career dates and descriptions live in `src/consts/career.ts`. The experience list and the chart in the hero both read from that file.
